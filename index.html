syslog 형식과 imfile 형식

syslog 형식 · 서비스가 직접 syslog로 기록

# haproxy.cfg
global
    log /dev/log local2
# /etc/rsyslog.d/49-haproxy.conf
local2.*    -/var/log/haproxy.log
& stop
# 모든 facility를 중앙으로
*.* call to_log01

imfile 형식 · 파일에만 기록하는 서비스

module(load="imfile")
input(type="imfile"
  File="/var/log/httpd/error_log"
  Tag="httpd-error:" Facility="local6"
  Severity="err" ruleset="to_log01")
input(type="imfile"
  File="/var/log/php-fpm/error.log"
  Tag="php-fpm:" ruleset="to_log01")

Logstash 파이프라인 · 필드 분리와 인덱스 분리

input  { beats { port => 5044 } }
filter {
  if [log_type] == "apache_access" {
    grok  { match => { "message" => "%{COMBINEDAPACHELOG}" } }
    date  { match => [ "timestamp", "dd/MMM/yyyy:HH:mm:ss Z" ] }
    geoip { source => "[source][address]" }
  }
}
output { elasticsearch { hosts => ["https://ES:9200"]  index => "logs-%{[log_type]}-%{+YYYY.MM.dd}" } }

A-2 접근 통제 · 암호화 · 가용성

iptables 순서
ESTABLISHED 허용 → INVALID 차단 → fail2ban(F2B) → 공용 차단 목록(BLACKLIST) → 서비스 허용 → LOG → DROP
firewalld
zone target DROP · rich rule로 출발지 + 포트를 함께 지정 · 관리 접속은 관리 주소에서만
UFW · TCP Wrapper
UFW: 기본 차단 · 출발지별 허용 (firewalld와 같은 Ansible 작업으로 관리) · TCP Wrapper: hosts.deny 'ALL: ALL' 여부를 점검 항목으로 확인 (Rocky 9는 tcp_wrappers 제거 → 호스트 방화벽으로 대체)
fail2ban
프록시 로그의 4xx · 429 응답 5분 20회 → 1시간 차단 · 차단 기록은 규칙 재적용 후에도 유지
차단 목록
공용 목록 하나를 모든 프록시 서버의 BLACKLIST 체인에 동시 반영 (VIP 이동 시에도 유지)
